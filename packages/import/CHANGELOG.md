# @acunsoft/datatable-import

## 0.6.0

### Minor Changes

- f721485: First release of `@acunsoft/datatable-import`: Excel and CSV import as an optional module. The import dialog (`openImport()`, `importButton()`; file and drag and drop, column mapping with a preview, progress, results, error report), the import protocol `acun-import/1` with its client, and a test kit for any back end (`@acunsoft/datatable-import/testing`). The back ends were already released: Laravel `TableImport` and Node `@acunsoft/datatable-server/import`.
